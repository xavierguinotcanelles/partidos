# Partidos

Web divulgativa, pública y sin ánimo de lucro sobre la genealogía de los partidos, federaciones y coaliciones políticas en España: cómo nacen, se unen, se separan y cambian de nombre. Empieza en el presente y navega hacia el pasado.

Este repositorio es **salida construida**: la web y los datos publicados. No se edita a mano; lo actualiza la integración continua del taller al fusionar cada cambio.

- Web: https://xavierguinotcanelles.github.io/partidos/
- Metodología (criterios editoriales vigentes): `metodologia.html`
- Datos: `datos/` (CSV, JSON, SQLite y esquemas), con fuente por fila

## Correcciones

Si encuentras un error, abre una issue con la plantilla «Corrección» e indica la fuente. Sin fuente verificable no se puede aceptar un cambio.
